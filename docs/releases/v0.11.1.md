# Stacker v0.11.1

- **History** opens while the selected layer loads. Its diff appears first, and **Back to changes** stays available during the load.
- Open a file for review and read its patch while full-file context, syntax highlighting, and discussion load.
- **Working tree** reads a normal snapshot in four Git calls. Staging and unstaging share one post-write status read for the file list and checkout indicators.
- Switching worktrees restores the local comparison earlier. Refresh reuses the current comparison when its inputs match.

## Performance

P95 time to usable content in 30 fresh-process samples on an Apple M1 Pro. The test repository had 25,000 tracked files, 500 changes, 20 stack layers, and PR objects available locally.

| Action | v0.11.0 | v0.11.1 |
| --- | ---: | ---: |
| Show the first History diff | 4.53 s | 454 ms |
| Open a file for review | 199 ms | 125 ms |
| Open the Working tree file list | 596 ms | 313 ms |
| Switch linked worktrees | 1.48 s | 377 ms |
