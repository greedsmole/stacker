# Stacker v0.6.0

This release brings versioned review history, a durable workspace foundation and Git execution in the opened
local repository to macOS Apple Silicon and Windows x64.

## Opened local repository

PR review, History, version comparison and stack analysis use the repository or worktree you opened. Missing PR
commits are fetched through its configured origin, using native Git SSH/HTTPS credentials, proxy and certificate
settings. Stacker retains code under its own refs and preserves HEAD, index, working files, Git configuration and
FETCH_HEAD during preparation and viewing. Linked worktrees keep their own command working directory.

Earlier private object repositories are imported into each connected local repository and retained as migration
sources. See [local repository execution](../LOCAL_REPOSITORY.md) for retention, cleanup and backup behavior.

## Review and workspace foundation

- Versioned change history and an embedded History panel preserve graph, checkpoint and review context.
- Persistent repository/worktree identities and explicit relocation retain workspace state across folder moves.
- Draft revisions, bounded autosave and transactional graph observations protect concurrent edits and recovery.
- Immutable publication payloads and persisted operation outcomes retain uncertain sends for reconciliation.
- Shared reads, cancellation, object leases and virtualized diff controls bound background work and retained data.
- Verified profile backup/restore includes metadata and a bundle of the active repository's retained history.

## Upgrade and installation

The application backs up older SQLite schemas before migrating to schema 3. Existing review metadata and drafts
are retained. Profile settings and metadata stay in application data; Git objects live in the opened repository.
The checkout and credentials are not included in profile backups. Legacy format-1 backups remain readable.

On Windows, extract the complete ZIP and run `Stacker/Stacker.exe`. On macOS, extract the TAR archive and open
`Stacker.app`. Both packages include the .NET runtime. Git and optional GitHub CLI are installed separately.
The macOS package is not Developer ID signed or notarized.

Verification evidence and platform limitations are recorded in [VERIFICATION.md](../../VERIFICATION.md).
