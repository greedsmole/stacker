# Stacker v0.11.0

- Browse PRs and local stacks in a branch graph. The filled node tracks the layer you are inspecting, and **HEAD** marks the checked-out branch. Fresh profiles open the graph beside the diff.
- Open **Working tree** to read staged and unstaged diffs, stage or unstage selected files, and commit the index with your Git hooks and signing settings. **Changes** returns to the selected comparison.
- Choose **GitHub CLI backend** under **Local stacks** to load and manage a stack tracked by the official `gh stack` extension. Create a stack, add a layer, and preview a local rebase of upper layers.
- Resolve a stopped GitHub CLI rebase in **Working tree**, then use the recovery banner to continue or abort. Stack management supports `gh stack` 0.3.x and was tested with 0.3.0. Earlier JSON-capable versions can display the stack.

| --- | --- |

Extract the archive, then open `Stacker.app` or `Stacker/Stacker.exe`. Keep the Windows executable beside the other files in its folder. The packages include .NET. Install Git separately and add the GitHub CLI for GitHub review and managed stacks.

Verify the downloads with `SHA256SUMS-v0.11.0.txt`. The macOS bundles ship without Developer ID signing or notarization.
