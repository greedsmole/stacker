# Stacker v0.8.2

- Split C# types into individual files across the app and tests. Private nested types keep their original scope.
- Added repository formatting rules for C# blocks and embedded SQLite. SQL uses multiline raw strings with aligned clauses and one list item per line.
- CI checks embedded SQL formatting and C# type layout.

## Downloads

| Platform | Package |
| --- | --- |
| macOS Apple Silicon | `Stacker-0.8.2-osx-arm64.tar.gz` |
| macOS Intel | `Stacker-0.8.2-osx-x64.tar.gz` |
| Windows x64 | `Stacker-0.8.2-win-x64.zip` |

Extract the archive before starting `Stacker.app` or `Stacker/Stacker.exe`. Keep the Windows executable alongside the other files in its folder. The packages include .NET. Install Git separately and add GitHub CLI for PR review.

Use `SHA256SUMS-v0.8.2.txt` to verify the downloads. The macOS app bundles are distributed unsigned.
