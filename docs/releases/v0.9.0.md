# Stacker v0.9.0

- Review stacked and standalone pull requests in a workspace centered on the diff. Discussion opens alongside the code on wide windows. On smaller windows, open it when needed and return with **Back to diff**.
- Browse the shared **Files** pane by list or folder, filter by path, and find unreviewed files. Comparisons across several layers group files by layer so repeated paths open the right patch.
- Start a stack from **Local stacks**. The selected stack's header puts **Add layer**, **Commit**, **Edit stack**, and **Preview restack** within reach and shows the checked-out branch beside **Commit**.
- Use **Focus** to hide the navigation panes and inspector while reading code. Stacker keeps your open diff and draft when you change the layout. Choose **Reduce motion** in Settings to disable workspace animations.
- History shares the file picker with Changes. Find, Refresh, and Settings have fixed toolbar positions, and maintenance tools are under **More**.
