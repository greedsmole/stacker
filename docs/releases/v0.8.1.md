# Stacker v0.8.1

- Restack can resume a rebase after a crash before the pending step was saved. Restore checks the selected journal entry and preserves separate Git operations. Undo can finish recording a restore after the refs are back in place and stops before changing any branch if a rewrite cannot be verified.
- Cancellation before dispatch prevents the command from running. When Git or GitHub has already replied, Stacker records the result before ending the command.
- Review recovers confirmed GitHub writes after a restart and keeps edits made after the send. When a stack PR batch stops on an unknown result, it names the affected layer and lists the writes already confirmed.
- The main window waits for saving or a close decision. History cancels older layer loads so the selected layer and its diff stay in sync.
