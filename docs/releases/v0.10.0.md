# Stacker v0.10.0

- Read code in a compact Fluent interface with consistent dark and light themes. PR/stack navigation starts closed, the Files pane defaults to 220 px, and comparison and file controls stay in single-row toolbars.
- Open **Discussion** and **Review** when needed. Resizing never opens the inspector. Inline conversations and saved draft bodies start collapsed, and **Escape** returns from review to the control that opened it.
- Find commands by scope in **Stack actions**, **PR tools**, and **File actions**. Native menus support keyboard navigation, Escape dismissal, and a checked **Wrap code** setting.
- Use **Discussion**, **File comments**, **All threads**, and **Submit** to choose a review task. Help text distinguishes local drafts from immediate posting. Publication buttons reflect required text, selected files or threads, and review decisions; existing publication safety checks still run before sending.
- Work through clearer settings, stack, commit, restack, recovery, and class-diagram dialogs. Fields have permanent labels, content scrolls at smaller sizes, and dialog actions stay visible.
- Existing settings adopt the compact layout once: PR/stack navigation closes, and the previous 248 px Files default becomes 220 px. Later explicit layout choices remain saved.
