# Stacker v0.8.0

- The new Stacker icon draws on Git branch and commit graphs. It appears in the desktop toolbar, the macOS app bundle, and the Windows executable.
- Browse changed files in a flat list or a folder tree. File rows show colored Git status letters, and the desktop uses a VS Code blue accent in both themes.
- Review History gives more space to the diff. Reveal hidden context near a change or open the full file. C# diffs offer navigation to symbol definitions and references when they can be resolved.
- Post consecutive inline comments while the discussion reloads. Publication errors appear in the composer. The command log shows GitHub CLI requests, and saved operations retain publication attempts across restarts.
