# Stacker v0.7.0

The desktop update reorganizes the review workspace and dialogs. History comparisons have their own file navigator so you can inspect files that appear only in an earlier comparison. Loading a different layer updates the shared workspace selection after the layer is ready.

Packages include the .NET runtime and are available for macOS and Windows on x64 and ARM64. On Windows, extract the full ZIP and run `Stacker/Stacker.exe`. On macOS, extract the tarball and open `Stacker.app`. The macOS app bundles are unsigned and unnotarized.

For local packaging, use `make publish` for your computer or specify a target, for example `make publish RID=linux-x64`. `make publish-all` packages all six desktop targets.
